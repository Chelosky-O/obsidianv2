> [!abstract] Objetivo del módulo
> Entender el concepto de **data lakehouse** y los productos de Google Cloud para crearlo. Un lakehouse usa **fuentes de datos abiertas (open-standard)** y combina lo mejor de un **data lake** y un **data warehouse**, resolviendo muchas de sus limitaciones.
