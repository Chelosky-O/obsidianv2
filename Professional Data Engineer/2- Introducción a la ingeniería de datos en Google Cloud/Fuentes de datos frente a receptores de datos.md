
Las fuentes de datos son el punto de partida del recorrido de los datos. Los datos sin procesar esperan para transformarse en información valiosa.
Cualquier sistema, aplicación o plataforma que cree almacene o comparta datos se puede considerar una fuente de datos.

# Productos de Google Cloud que se usan para la fase de #Transferencia

## Cloud Storage
Un datalake que contiene varios tipos de fuentes de datos.

## Pub/Sub
Un sistema de mensajes asíncrono que entrega datos de sistemas externos.

---
  
La etapa de transformación de una canalización de datos representa a las acciones que se realizan en una fuente de datos para ajustar modificar, unir o personalizar una fuente de datos para que concuerde con datos específicos downstream o requisitos de informes.

Hay 3 patrones de transformación principales extracción y carga extracción, carga y transformación y extracción, transformación y carga.


---

Un receptor de datos es la parada final del recorrido de los datos. Allí, los datos procesados y transformados se almacenan para su uso en el futuro su análisis y la toma de decisiones.

# Productos de Google Cloud que se usan para la fase de #Almacenamiento

## BigQuery 
Un almacén de datos sin servidores
## Bigtable
Una base de datos NoSQL altamente escalable.

---
# Tipos de datos

## Estructurados
También están los datos estructurados que representan la información almacenada en tablas, filas y columnas.
## No estructurados
Los datos no estructurados son información almacenada de forma no tabular como documentos, imágenes y archivos de audio.
Los datos no estructurados suelen ser más apropiados para Cloud Storage pero BigQuery también permite almacenar datos no estructurados en tablas de objetos.
